# Site de Manuais

Sistema de gerenciamento de documentos e manuais em PDF, desenvolvido com ASP.NET Core Razor Pages.

## 🚀 Funcionalidades

- **Gestão de Categorias**: Organize documentos por categorias
- **Gestão de Módulos**: Agrupe documentos por módulos
- **Upload de Documentos**: Faça upload de arquivos PDF (até 10MB)
- **Área Administrativa**: Painel completo para gerenciar conteúdo
- **Pesquisa e Filtros**: Encontre documentos facilmente

## 🛠️ Tecnologias

- .NET 8.0
- ASP.NET Core Razor Pages
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Bootstrap Icons

## 📋 Pré-requisitos

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- SQL Server (LocalDB ou SQL Server Express)
- Visual Studio 2022 ou Visual Studio Code
